# CISTERN

Sanitation duty in an Emacs buffer. Sector 7, 34 by 16 cells of a
structure nobody finished and nobody will. Workers mine ore. Their
bladders fill. You wire toilets to tanks by pipe, purge the tanks,
clean what leaks. Contamination is the clock. THE STRUCTURE DOES NOT
CARE.

Each worker carries a dossier — FLOW, GRIT, NERVE, ARCHIVE — rolled at
the gate. The sector keeps a story: a premise banner, three acts, hooks
that hold or breach. The palette derives itself from your theme. The
Structure does not explain itself either.

## Run it

```sh
git clone https://github.com/boundring/cistern
emacs -Q -l src/cistern.el
```

Then `M-x cistern`, or see [PLAYING.md](PLAYING.md) for the full guide.
